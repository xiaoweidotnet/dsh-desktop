# Security Policy / 安全政策

## 中文

请不要在公开 Issue 中发布 API Key、凭证、私人工作区内容或可利用的安全漏洞细节。发现安全问题时，请通过 GitHub 仓库所有者资料中的私密联系方式报告，并提供受影响版本、复现步骤和影响范围。

本项目是桌面封装。若漏洞确认来自 DeepSeek Harness npm 运行时，也请同时按照上游项目的安全流程报告。

## English

Do not publish API keys, credentials, private workspace contents, or exploitable vulnerability details in a public issue. Report security concerns through a private contact method listed on the repository owner's GitHub profile, including the affected version, reproduction steps, and impact.

This project is a desktop wrapper. If the vulnerability originates in the DeepSeek Harness npm runtime, please also follow the upstream project's security reporting process.
